语流｜0.9.1 通用定义模型主导版

当前能力
1. 用户先选中文字，再双击刚才的选区。
2. 选区保持金色高亮；滚动页面时高亮跟随原文保留。
3. 卡片始终固定在浏览器右侧，不再插入文章内部；可覆盖右侧推荐、目录或广告，但不主动改动正文排版。
4. 卡片会根据正文右侧的剩余空间，在 300–390 像素之间自动调整宽度，尽量避开正文。
5. 卡片高度随内容自适应，最高 600 像素，超出后在内容区滚动。
6. “这里指什么”和“作者想表达什么”采用流式输出。
7. “说简单点”可流式生成；通用定义在完整生成并通过检查后一次性显示，避免错误草稿闪现。
8. 只调用 GLM-4.7-Flash 和 GLM-4-Flash-250414 两个免费模型。
9. API Key 保存一次即可；重新加载插件和刷新网页不会清除。
10. 可在插件设置中主动开启“开发诊断模式”，按一次选词解释为单位记录搜索、辨义、来源、模型原始输出、规则检查、最终显示结果和耗时。
11. 通用定义先由模型辨义并起草。成熟概念可直接解释；新颖、多义或具体专名按需检索核对。搜索失败不会自动抹掉已有的可信草稿。

开发诊断后台
1. 点击 Chrome 工具栏中的“语流”图标。
2. 打开“开发诊断模式”，再点击“打开诊断后台”。
3. 记录只保存在本机，最多保留最近100次；不会保存 API Key 或整篇网页正文。
4. 需要协助排查时，可从诊断后台导出 JSON 文件。

安装方法将在完成本地检查后逐步进行。
