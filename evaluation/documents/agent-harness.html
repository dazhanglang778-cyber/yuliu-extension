Agent 如何在环境中持续运行

一个 Agent 不只需要模型，还需要任务、工具、状态和可以观察结果的环境。

环境负责提供任务条件与反馈，模型则根据反馈决定下一步行动。

为了让这一过程稳定重复，系统需要保存会话状态、调度工具调用并记录每次执行结果。

这里把组织这些交互环节的运行框架统称为 Harness。它连接模型、工具和环境，但不是某一家公司的专有产品。

随着模型能力提升，Harness 的设计会直接影响任务能否可靠执行以及经验能否被下一轮利用。
