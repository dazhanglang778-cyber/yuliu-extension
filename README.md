# 语流 · 网页语境解释插件

选中文字，再双击选区，理解它在这里具体指什么；支持“说简单点”“展开讲讲”和原文依据定位。

## 在另一台电脑安装

本版为桌面 Chrome 手动安装试用版，不是 Chrome 应用商店版本，也不是手机应用。

1. 在本仓库 Releases 页面下载 `yuliu-extension-0.9.2.zip`（若尚无 Release，请等待发布者上传安装包）。
2. 将 ZIP 完整解压到固定目录。不要直接打开 popup.html，也不要安装后删除或移动目录。
3. 在 Chrome 地址栏输入 `chrome://extensions`，打开“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的文件夹。
5. 点击工具栏拼图图标 → 语流，选择模型服务商。填写你自己的 API Key，点击保存。
6. OpenAI 用户可点击“测试已保存的 OpenAI 连接”；测试会消耗少量 API 额度。
7. 刷新需要阅读的网页，选中文字后双击选区。

若下载的是 GitHub 自动生成的 Source code 压缩包，解压后选择含 manifest.json 的源码根目录。首次建议用公开文章测试，不要直接测试客户或公司机密文档。

## 使用边界

- 需自备可用的 OpenAI 或智谱 API Key；模型调用费用和服务可用性由对应服务商及账号决定。安装包不附带开发者密钥或公共额度。
- 支持哪些模型以设置页为准，不会在失败时悄悄切换到其他服务商。
- 网页需允许扩展运行；浏览器设置页、扩展商店等受限页面不能正常注入。扫描件、图片中的文字和动态长文的完整采集不作保证。
- AI 输出可能出错；引文存在不等于所有推断均正确，请核对重要信息。
- 本版保留开发诊断与实验页面；首次试用只需常规双击流程，不需要运行付费评测。
- 当前错误提示仍可能合并额度不足与限流等原因；有问题可在 GitHub Issues 提交脱敏描述。

## 隐私与安全

解释时，选中内容和相关原文会发送给所选模型服务商。API Key 保存在本机扩展存储中，该存储不是加密保险库。不要将密钥放入代码、Issues 或截图，也不要分发浏览器用户配置目录。

开发诊断默认关闭。开启后，记录只保存在本机，可能包含原文片段和模型输出；不应直接公开上传诊断 JSON。详见 [隐私说明](PRIVACY.md)。

## 更新

从 GitHub 手动安装不会自动更新。下载新版，解压到同一个固定安装目录，然后在扩展管理页点语流的“重新加载”，并刷新阅读页面。不要先卸载扩展；卸载可能清除本机保存的设置。

另一台电脑需要重新填写密钥。本项目没有提供云端设置或阅读记录同步。

## 开发与打包

使用 Node.js 运行离线测试：PowerShell 中执行 `./run-tests.ps1`。

执行 `node scripts/build-release.cjs` 生成白名单安装目录和 SHA-256 文件清单，再执行 `Compress-Archive -LiteralPath (Get-ChildItem dist/yuliu-extension-0.9.2).FullName -DestinationPath dist/yuliu-extension-0.9.2.zip` 打包。脚本拒绝覆盖已有输出，避免覆盖旧包。

安装包不包含 .git、测试目录、诊断导出、内部文档、node_modules 或浏览器存储。438 项离线自动化测试通过不代表跨设备实测或模型回答正确率。
